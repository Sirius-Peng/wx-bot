# 自选旧目录导入 · v2.1.4

这是v2.1.4新增功能；最近已发布的v2.1.3只支持首次自动非覆盖迁移。版本与发布记录见[首页](../README.md)。

## 用户操作

1. 打开旧版「文件 → 打开数据目录」，确认里面有 `config.json`；复制一份完整备份，从托盘退出旧版（关闭窗口只是隐藏）。
2. 在新版打开「模型与行为 → 导入旧版数据」。桌面版点击「选择旧目录…」，浏览器版填写运行后端那台机器上的绝对路径。选择数据目录，不选安装器、`.app` 或 `data` 的上一级。
3. 点击「预览导入内容」。界面显示文件数、目录数、大小，以及是否含人格设置、长期记忆、消息记录、微信状态和上下文，不显示Key或聊天正文。
4. 勾选「我确认替换当前配置与记忆，并已退出旧版本」，点击「准备导入」。旧资料快照通过逐文件SHA256校验后暂存；此时当前配置仍保持不变，可取消任务。
5. 桌面版点击「重启后台并完成导入」。浏览器/源码用户退出并重新启动后端进程；「重启机器人」只重启通道，不会导入。后台旧进程退出后，新进程在加载配置、记忆、身份验证等组件前创建当前数据的校验备份，再执行导入。
6. 界面重载后检查「旧目录已导入」及导入前备份文件名，核对人格、模型和接入设置。微信/QQ平台可能需要重新确认登录。

已经使用过新版、已生成默认配置或自动迁移标记的用户也适用。此操作采用整套替换，不把两套不同身份的记忆混在一起；新版中未出现在旧目录的活动文件会先备份再移出活动状态。未保存的界面草稿不会自动带入。

## 内容与保存位置

- `config.json`：名称、人格、关系模式、模型Key、行为、搜索及接入配置。旧版缺失 `persona_profile` 但有明确人设的配置仍按自定义人格加载；不强制覆盖为弗洛洛预设。
- `memory.json`、上下文JSON、消息记录、学习队列及版本备份、`ilink/`、引导状态、管理员Token等普通文件恢复到当前独立用户目录。
- 未知扩展文件、普通隐藏文件、用户自己的临时文件及空目录也保留，不仅仅导入几个已知配置。
- 旧 `logs/` 完整放到 `logs/imported-<任务ID>/`，不替换桌面进程正在写入的日志。
- 旧 `.backups/` 完整放到 `.backups/legacy-<任务ID>/`，不覆盖新版刚创建的导入前备份。
- 根目录内部 `.storage*` 锁/事务/迁移控制、`.imports`、`.migration-*` 以及保留的备份清单名称由新版管理，不照搬旧控制状态。
- 源资料校验ZIP：`.backups/wxbot-import-...zip`；导入前的活动数据ZIP：`.backups/wxbot-preimport-...zip`。取消任务不删除已校验的源ZIP。
- 旧配置的绝对微信路径若位于所选目录（或其已记录的自动迁移来源且该资料确实在本目录），会重新指向新数据目录；其他外部路径保持不变。

目录外的微信资料、QQ NapCat Docker持久卷、模型供应商账号及模型权重不在所选目录内，本次不复制它们。具体目录与Docker备份边界见[用户数据](user-data-persistence.md)。

## 失败与恢复

- 预览15分钟有效，源文件变化需重新预览；旧目录快照准备失败不替换当前数据。
- 旧/新目录不能相同或互相包含；源必须含有效配置，不能含符号链接、特殊文件、跨Windows不兼容文件名或大小写冲突。当前限额30000个文件、30000个子目录、4GiB；超限先整理历史备份。
- 导入在启动存储锁内执行。已进入发布阶段的任务保留原始导入前ZIP；进程中断后从同一份源ZIP续跑，不用半套状态创建新的基线备份。
- 普通写入失败会清理已写入的活动资料并恢复导入前ZIP，界面显示失败状态；如果磁盘持续不可写或原始备份损坏，后台保留事务及备份供检查，不宣称恢复成功。
- 回退整个导入：退出应用，额外备份当前目录，再把 `wxbot-preimport-...zip` 的文件恢复到一个独立空目录（保留目录层级，不将 `__wxbot_backup_manifest__.json` 当配置），设置 `WXBOT_DATA_DIR` 为该目录后启动。活动记录会回到导入前状态；日志与历史备份仍在原目录。
- 管理员Token随旧数据恢复，本机页面重载重新建立管理会话；远程访问需使用恢复后的Token。

本机管理端点：`POST /api/data/import/preview`、`prepare`、`cancel`；均需要管理认证与同源验证，仅接受本机客户端。准备接口必须提交服务器签发的预览Token及 `confirm_replace: true`，不接受任意外部路径直接覆盖。

## 验证

合成旧/新资料回归覆盖预览、确认、原文件不变、最新数据备份、整套替换、未知二进制、空目录、历史日志/备份、微信路径、取消、预览过期/变更、认证、失败恢复与中断续跑。

```sh
python -m unittest discover -s tests -p test_data_import.py
node tests/test_data_import_frontend.cjs
python tools/smoke_data_import.py
# 指定实际冻结后端，同样检查HTTP导入及跨进程重启：
python tools/smoke_data_import.py --backend /absolute/path/to/wxbot-server
```

这些测试使用临时合成资料，不表示已导入用户的真实人格或聊天数据。
