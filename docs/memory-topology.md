# 记忆拓扑：看见对话与了解的关联

> 本功能随v2.1.7发布。此图展示本地已经保存的关联，不读取模型内部思维，不改变渐进记忆的形成规则。

## 使用方法

进入左侧 **「记忆拓扑」**，先浏览关联网络，再按需展开筛选或点选节点追溯来源。界面参考 [Obsidian 官方 Graph view](https://obsidian.md/help/plugins/graph) 的图优先、轻量节点、关联聚焦及局部图机制，适配本项目的记忆阶段和用户原话，不复制它的笔记功能，也不展示模型内部思维。

- **全局 / 局部**：全局图显示当前筛选快照；选中一个节点后进入局部图，只看它附近一至三层的真实连线。局部根节点保持固定，继续点选邻居不会让整幅图跳到另一处；可随时返回全局。
- **悬停 / 点选**：悬停临时强调该节点及直接关联，移出后恢复已选节点的聚焦；点选打开来源详情。选择本身不重新计算布局、不重置缩放。
- **拖动与缩放**：拖动空白处平移，拖动节点整理局部位置；鼠标滚轮围绕指针位置缩放，也可使用「＋ / −」和适应视图按钮。拖动后的松手不会误触节点点击。
- **筛选与显示**：按对象、渠道、阶段、关键词或节点类型筛选；勾选「显示历史与已淡化记忆」后查看历史状态。文字密度和节点大小只改变呈现，不改变记忆内容或强度。
- **来源详情**：展示完整可用文本、阶段、用户证据次数、时间及直接关联；点击关联可继续追溯。关闭详情后网络保持原位置。
- **全屏与键盘**：可扩展图区域进行阅读；节点与节点列表均支持键盘选择。缩放、方向键平移和退出操作不依赖鼠标；浏览器原生全屏不可用时仍可扩展页面中的图区域。
- **刷新拓扑**读取最新本地状态，机器人未启动也能查看。切换筛选时旧请求会取消，读取失败会清空旧结果，避免把上一份图误当成新结果。
- 默认最多 **160 个节点**，页面可选 60 / 160 / 300。达到上限时会提示；选择单个对象或进一步搜索，可查看局部关联。
- 左下角计数对应当前可见节点；局部或类型筛选后同时提示「已显示 / 已读取」数量，局部状态注明固定中心和层数，避免把快照总量误认为眼前子图。
- 「节点列表」提供图形之外的完整文本选择入口；各类型使用颜色、图例和文字标签区分。缩小时隐藏部分文字以减少遮挡，聚焦或放大时再显示。

筛选中可以搜索「音乐」「旅行」「某个约定」等词。微信和 QQ 可分别查看；只有已经明确关联的两个账号才汇聚到同一对象，不凭昵称或相同账号字符串推断身份。只使用其中一个渠道也可正常使用。类型开关、局部深度、悬停、布局及显示设置均在浏览器本地处理，不产生新记忆或外部网络请求；对象、渠道、阶段、历史、关键词和节点上限仍从只读管理 API 获取受限快照。

此页面为只读视图。手动添加、固定、解除固定和明确遗忘，继续在「人格知识库」操作；更改后刷新拓扑即可。仅查看、搜索或点选图节点，不增加命中次数，不续期，不唤醒淡化的记忆，也不调用模型或收费搜索服务。

## 节点与连线表示什么

| 图中元素 | 含义 |
|---|---|
| 「对象」节点 | 一个独立账号、明确关联的一组账号，或有明确作用域的群聊/通用手动记录 |
| 「记忆」节点 | 已保存的候选印象、稳定认知、临时状态或手动固定记录；阶段与强度在详情中展示 |
| 「对话 / 来源摘录」节点 | 近期上下文中的真实用户来话，或记忆保留的逐字用户依据；两者在详情中明确区分 |
| 「关键词」节点 | 记忆条目已有的关键词，不由图页面临时生成新事实 |
| 实线「关于此人 / 交流经历」 | 保存的所属关系或实际交流经历；一次交流不代表已经形成长期记忆 |
| 实线「用户原话依据」 | 该记忆记录保存了逐字用户证据；能定位近期原文且摘录相符时连到原文，否则展示为来源摘录 |
| 实线「事实版本更新」 | 同一对象、同类别中已经保存的明确版本指向，不按关键词相似度猜测 |
| 虚线「共享关键词」 | 同一对象下的字面关键词关联，**不代表因果、模型推理路径或新增认知** |

节点统一使用轻量圆点，半径随关联数量温和增加，便于发现连接较多的中心节点。**节点大小不代表记忆置信度、感情深浅、重要程度或被记住的强度**；淡化、固定等阶段仍以详情为准。局部图的每一层都沿现有连线展开，不用文字相似度临时补边。

例如，用户先说「我最近在听爵士」，这可以只是一段交流经历；在后续独立对话中再次明确表达，后台按既有规则形成了关于音乐偏好的记忆，才会出现记忆节点和原话依据连线。助手自己提起「爵士」，不会成为新的用户证据。

手动记忆标注为「手动添加，不代表从对话推导」，没有依据时不制造一条来源消息。原始上下文已压缩时，图会显示「来源摘录」和实际保留的用户原话，不拼造当时的完整聊天或助手回答。来源时间不明时标为「时间未记录」，不把打开图的时间当成证据时间。

## 展示范围与明确遗忘

图只读取活动用户目录中的：

- `memory.json` 的记忆、来源与显式身份关联；
- `memory-forgotten.json` 以及记忆快照中的持久遗忘屏蔽；
- `context-wechat.json`、`context-qq.json` 的近期上下文。

它**不从物理聊天日志、后端日志、旧备份、旧摘要、待抽取任务或人格示例反推记忆**。因此，图不是全部聊天记录的完整索引，消息记录数量也不等于图中对话节点数量。静默未回的真实用户来话可以出现；只有助手的主动消息不会被展示成用户原话或巩固依据。

每个近期会话最多读取最近 1,000 条上下文，合计最多选取 2,000 条，再按图节点上限裁剪；单份状态文件读取上限为 16 MiB。每条记忆最多展示三个来源和四个关键词，另补充最多 80 段独立近期对话。图会提示节点截断及损坏、超限、来源不可验证而未展示的记录，未显示不代表数据已删除。

明确遗忘屏蔽先于阶段、历史与搜索筛选：即使旧上下文文件或物理日志仍有内容，勾选历史也不重新展示被屏蔽的记忆、依据或相关关键词。助手的历史转述没有逐句来源，因此对于有遗忘屏蔽的对象，图会保守隐藏其助手历史文本；群聊存在屏蔽时同样保守隐藏助手文本。完整聊天日志的物理删除依旧是独立操作，见[渐进记忆](memory-design.md)。

群聊上下文按可验证的来源消息标识定位发言者；缺少明确发言人、混合多人来源的旧记录不猜测归属、不挂到某个私聊用户。群作用域记忆与个人记忆使用不同对象节点；未经关联的微信/QQ账号保持独立。

读取图不触发旧数据迁移，不创建学习任务或修改配置；身份/屏蔽状态损坏、文件读取预算超限时返回读取失败，而不是忽略屏蔽并显示旧事实。管理接口沿用现有管理认证与同源检查。浏览器显示的文字按纯文本处理，不把对话中的 HTML 或链接当成页面代码执行；图使用本地脚本与 SVG，无新增外部图服务或 CDN。

## API

`GET /api/memory/graph`，使用现有管理 Cookie 或 Bearer Token。

| 参数 | 默认值 | 说明 |
|---|---|---|
| `platform` | 空 | 空、`ilink` 或 `onebot` |
| `person` | 空 | 响应 `people` 数组中的不透明对象 ID；空表示所有对象 |
| `phase` | 空 | 空、`candidate`、`stable`、`temporary`、`dormant`、`pinned`；淡化项需同时开启历史 |
| `keyword` | 空 | 搜索记忆、保留依据、近期文本和关键词，最多 120 字符 |
| `include_history` | `false` | 是否包含淡化、已更正或被更新的记忆；不绕过明确遗忘 |
| `limit` | `160` | 总节点上限，20～300 |

返回字段：

- `version: 1`、`generated_at`：图格式和本次快照生成时间。
- `nodes`：`person / memory / conversation / topic` 节点，含展示文字和相应来源、阶段等元数据。
- `edges`：`source / target / kind / label / derived`；`derived=true` 的关键词边只作字面关联。
- `people`：对象筛选选项；`stats`：本次显示的各类型节点数。
- `coverage`：记忆总数、匹配数、已展示数、可用近期对话数、节点上限、截断及未展示记录提示。
- `filters`、`notice`：本次筛选及图含义说明。

节点 ID 是稳定的本地派生标识，不是可直接操作的外部消息凭据。响应不返回模型 Key、微信上下文 Token、媒体下载地址或原始协议包。管理页本身仍有权查看对话文字和账号 ID，使用与其他管理功能相同的访问边界。

非法筛选返回 `400`，类型解析异常返回 `422`；未登录为 `401`，来源不匹配为 `403`；状态损坏、超限或暂不可读为 `503`。错误消息不回显本地文件路径或状态文件正文。

## 开发与验证

核心构建逻辑在 `src/core/memory_graph.py`，运行时只读聚合与管理 API 在 `src/runtime.py`、`src/server.py`，本地布局与交互在 `src/web/memory-graph.js`。没有新增数据库、第三方图依赖或自动学习写入。

在已安装项目依赖的环境执行：

```sh
python -m unittest tests.test_memory_graph tests.test_memory_graph_integration -v
node tests/test_memory_graph_frontend.cjs
python tools/check_docs.py
```

回归使用临时目录和合成内容，覆盖 100 次查看不写盘/不续期、真实原话与摘录区分、单端及显式跨端身份、群聊边界、生命周期与版本、持久遗忘、旧日志隔离、总量裁剪、参数和认证、状态损坏与重新刷新。界面测试另覆盖布局缓存、悬停/选择不重建 SVG、按关联数定半径、局部层级与类型筛选、指针锚定缩放、拖动取消、标签避让、键盘与全屏退出、筛选取消、纯文本渲染和错误清空。
