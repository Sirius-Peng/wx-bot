# 高频词、话题与气泡图

> 当前状态：已随 [v2.1.3](https://github.com/Sirius-Peng/wx-bot/releases/tag/v2.1.3) 发布；文档同步于2026-10-14。使用与测试范围见[文档索引](README.md)及[验证矩阵](validation.md)。

侧栏「对话统计」提供气泡图和带频率条的排行。气泡面积与当前频率成正比，不用半径直接冒充频率；点击或键盘 Enter/空格选择气泡，查看次数和涉及消息数。小气泡可能不显示内部文字，完整标签/数值仍可通过排行、可访问名称和提示查看。图表纯本地 SVG，不使用 CDN 或外部图表服务；窗口改变时重新布局。

## 筛选与计数

- 默认近30个自然日、微信与QQ、用户入站消息、全部会话、前20项、至少出现2次。
- 可选近7/30/90天或全部记录，微信/QQ，用户/机器人/双方，私聊/群聊，前10/20/30/50项，最低1/2/3/5次。
- 以配置的会话时区（默认Asia/Shanghai）分自然日，包含今日和此前N−1日，不是简单过去N×24小时。未来日期记录不纳入。
- 高频词使用 Jieba 精确分词（HMM关闭），合并英文大小写、过滤内置停用词、单字、纯数字、常见图片/语音占位符、URL/邮件/长数字/常见凭证格式以及代码块。
- 同一条消息“音乐 音乐 咖啡”产生音乐2词次，音乐涉及消息数1。词次与消息数是不同口径，界面分别展示。
- 高频话题采用公开可审阅的本地关键词规则，覆盖工作、学习、技术、游戏、音乐、饮食、健康、运动、旅行、关系、生活等类；不声称使用LLM理解语义。同一条有效文本可命中多个类别，每类别每条只计1次；因此各类百分比之和可能超过100%。没有命中规则的有效文本列为“未归类”。展示命中关键词便于核查。
- “有效文本”指经过清理后仍有合格词语的日志条数；纯图片占位、语气词等不计为有效文本，但仍出现在纳入消息总数。
- 旧日志未标记平台时仅在全部平台筛选中展示，不猜测微信/QQ归属。

## 本地历史与性能边界

数据来自独立用户目录的 `messages.jsonl`，不是界面内存里最近2000条。历史日志在更新/卸载重装后仍可读取，统计不额外调用模型、不发送到搜索服务，也不返回原文、账号或会话ID字段。统计结果属于本机私有资料；常见格式过滤不是完整敏感信息检测，普通词语中的人名/信息仍可能进入本地排行。

首次统计在线程中读取有限快照、逐行解析和分词；文件读取句柄在分词前关闭，避免 Windows 清空/替换日志被长时间阻塞；共享只读词典，不共享不同日志的统计数据。文件 inode/大小/mtime 或时区变化时重新计算，否则切换筛选复用日粒度汇总。无新增持久索引、无额外原文副本；重启时从原日志重建。

为避免超大日志耗尽内存，一次最多读取最近32MiB；单行超过256KiB整行跳过；单条文本最多8000字符；最多保留30000个不同词语。发生截断、损坏/未完成记录或词汇上限时界面明确提示，不把截取结果称为全量历史。分析期间文件被追加、删除或截断时本轮可能是先前快照，显示提示并在下次刷新更新；不会因文件缩短循环卡死。

清空消息记录后，下一次进入统计或刷新会同步变为空；本功能不会自行删除人格或记忆。默认仅在进入页面、筛选变化或用户刷新时分析，不给聊天发送链路加额外LLM调用。

## 接口与打包

`GET /api/statistics?days=30&platform=&direction=in&chat_type=&limit=20&min_count=2`

沿用现有管理员认证和同源保护。参数无效返回400/422；依赖或日志访问异常返回503，不把原始异常/密钥暴露给网页。Python依赖加入 `jieba>=0.42.1,<0.43`，macOS/Windows的PyInstaller配置收集Jieba词典资源。

Jieba精确模式依据：https://github.com/fxsjy/jieba 。统计依赖独立分词器，没有下载用户词典或远端训练语料。

## 验证

合成JSONL覆盖词次/消息频次、平台别名、日期和时区、机器人排除、重复关键词/多话题、超2000条历史、重启、文件缓存/追加/替换/删除/中途截断、清空、坏行、范围提示、字段脱敏、认证、错误处理和工作线程。前端测试覆盖气泡面积比例、无重叠、窄布局边界、键盘选择、标签注入无执行、旧请求成功/失败均不覆盖新筛选、空结果及错误状态。
