第一次安装 Docker 怎么操作？
  1. 按安装程序完成 Docker Desktop 安装；Windows 按提示启用 WSL2，需要重启时先重启电脑。

  3. 回到这里再次点「启动 QQ 网关并登录」。应用会继续，不会清空已有 QQ 登录数据。
