          群聊如何工作
          
机器人不是「有问必答」，而是通过五层漏斗判断该不该插话：@机器人 / 唤醒词 → 黑名单与静默时段 → 启发式打分 → 小模型判定 → 冷却与配额。
             最终只有约 1~2% 的群消息会被回复，避免刷屏惹人反感。
